# Точность оценки

Совпадение ответов ИИ с ручной разметкой (`tests/golden.json`, `tests/eval_golden.py`). Модель: Anthropic `claude-haiku-5-5`, `LLM_EFFORT=medium`, `EVAL_MODE=single`, один запрос на диалог (~$0,0025 по оценке).
Разметка DEV (60 чатов) написана ассистентом команды как черновик и частично спорная (поле `uncertain`); разметка TEST (17 чатов) от тимлида. В отчёт идут только основные диалоги DEV (56), отложенные (4) пока не смотрели.

| Прогон | DEV (56) | TEST (17) |
|---|---|---|
| v5 (база) | 82,1% | 80,1% |
| v6: правила «выявление потребности» и «идентификация» | 83,9% | 86,0% |

По критериям (v5 → v6):

| Критерий | DEV | TEST |
|---|---|---|
| Выявление потребности | 75,0 → 94,6 | 64,7 → 94,1 |
| Идентификация | 96,4 → 96,4 | 94,1 → 100 |
| Консультация | 64,3 → 57,1 | 58,8 → 58,8 |
| Ведение диалога | 80,4 → 73,2 | 76,5 → 82,4 |
| Завершение | 55,4 → 66,1 | 64,7 → 64,7 |
| Грубые нарушения | 96,4 → 94,6 | 94,1 → 100 |

Полные отчёты: `docs/accuracy/*.json`.

Ограничения: выборки маленькие, модель недетерминирована (температуру на Claude Haiku 5.5 задать нельзя), поэтому изменения в 2–5 пунктов могут быть шумом. Разметка DEV — не экспертная.
